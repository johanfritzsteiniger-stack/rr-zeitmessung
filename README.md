# Rocket Rookies – Biathlon Zeitmessung

Offline-fähige Web-App (PWA) zur Zeitmessung bei Biathlon-Wettkämpfen: Sprint/Prolog, Einzel, Verfolger, Massenstart.

**App öffnen & installieren:** https://johanfritzsteiniger-stack.github.io/rr-zeitmessung/

- Chrome/Edge (Laptop, Android): auf der Startseite „Installieren“
- iPad/iPhone (Safari): Teilen → „Zum Home-Bildschirm“
- Einmal mit Internet öffnen, danach funktioniert die App auch offline.

Alle Wettkampfdaten werden ausschließlich lokal auf dem jeweiligen Gerät gespeichert – dieses Repository enthält nur den Programmcode.

## Updates
Nach Änderungen an `index.html` in `sw.js` die Konstante `VERSION` erhöhen. Installierte Geräte zeigen dann „Neue Version verfügbar“.
